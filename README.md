# servicereport888

## ระบบภายในโปรเจกต์

- `/` หน้าเลือกระบบ
- `/building-login` ระบบรายงานตรวจสอบอาคารประจำปี
- `/service/` ระบบรายงานการบริการ

ระบบตรวจสอบอาคารและระบบรายงานการบริการใช้ Backend, Login และฐานข้อมูลคนละชุดกัน
เพื่อไม่ให้บัญชีผู้ใช้และข้อมูลรายงานของทั้งสองระบบปะปนกัน

### เริ่มใช้งานครั้งแรก

```powershell
npm install
npm run service:setup
```

สร้าง `service/backend/.env` จาก `service/backend/.env.example` และใส่ค่า
`DATABASE_URL` ของฐานข้อมูลระบบรายงานการบริการโดยเฉพาะ

### รันทุกระบบพร้อมกัน

```powershell
npm run dev:all
```

คำสั่งนี้เปิดหน้าเว็บ, API ระบบตรวจสอบอาคาร และ API ระบบรายงานการบริการพร้อมกัน
